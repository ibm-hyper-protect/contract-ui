# Contract input guidance

Add workload and Add environment provide Carbon accordions describing input preparation, value provenance, persistent volumes and runtime certificates. Signing and attestation forms explain their distinct passphrases and the difference between registering a key and verifying guest evidence.

Examples contain placeholders only. Obtain image addresses and application settings from your registry and application documentation, registry credentials from IAM, syslog TLS configuration from the log receiver operator, and the matching runtime encryption certificate from a trusted runtime provider. For existing encrypted data retain both original volume seeds.

Guidance changes no payloads, permissions, encryption or API behavior.
